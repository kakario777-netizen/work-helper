# 업무 도우미 (WorkHelper)

윈도우용 업무 보조 프로그램.

- **텍스트 정리**
  - 원고 검사: 메모장 파일 여러 개를 끌어다 놓으면 파일별 키워드(자동 인식·수정 가능)·키워드 수·공백 제외/포함 글자수·금지어 횟수
  - 보고서 정리: `키워드 링크 순위 병원명` → `링크 [병원명] 키워드`
  - 줄바꿈 정리
- **이미지 관리**: 대량 크기 조절·압축, 포맷 변환, 파일명 일괄 변경, 색감 조절 16종 (기본 저장: 원본 폴더 안 output)
- **이미지 캡쳐**: 병원·시술별 이미지를 보관해 두고, 폴더 개수만큼(폴더마다 원본 전부) 테두리 자르기 + 크기·비율 흔들림 + 미세 색감 + 새 메타데이터 → `바탕화면\병원명 시술명 N\output`
- **썸네일**: 병원별 썸네일 보관, 랜덤 자르기(750~950) → `바탕화면\병원명 썸넬 N`

보관 위치: `내 문서\업무도우미`

오른쪽 위 '설정'에서 탭·세부 탭을 숨기거나 순서를 바꿀 수 있습니다.
